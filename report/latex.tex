\section{Overview}

The Mini Game Hub is a secure multiplayer gaming platform where two authenticated users can play multiple games through a graphical interface. The system integrates Bash for authentication using SHA256 algorithm to store the encoded passswords and Python for game execution, data recording, and analytics. 
The games implemented include Tic Tac Toe, Othello, and Connect Four, each with unique mechanics and win conditions and a common base class. The platform also features a leaderboard and statistical graphs to track player performance and game popularity.
The basic game flow is that the users log in, select a game, play against each other, and then the results are recorded for leaderboard and analytics purposes.

\section{Authentication System}

\begin{itemize}
    \item Two users log in using their username and password.
    \item Their credentials are verified against the users.tsv file using Bash.
    \item Then the passwords are hashed using SHA256 algorithm and stored in users.tsv for security.
    \item New users can register if they don't have an account, and their credentials are added to users.tsv.
    \item After login, Python game engine is launched , which shows the game menu and allows users to select a game to play.
\end{itemize}

\begin{verbatim}
python3 game.py <username1> <username2>
\end{verbatim}

\section{Game Engine}
Game engine is responsible for handling the game logic, user interactions, and data recording. It is implemented in Python using Pygame for the graphical interface and NumPy for board representation and win condition checking.
It shows the game menu, allows users to select a game, and then runs the selected game. After the game is over, the game over menu appears,which has options to play again, return to the main menu, or show leaderboard.
If the users choose to play again, the same game is restarted. If they choose to return to the main menu, they are taken back to the game selection screen. If they choose to show leaderboard, the leaderboard menu with sorting options appears, which allows users to view the leaderboard based on wins, losses, or win/loss ratio.

\begin{itemize}
    \item Player handling
    \item Turn switching
    \item NumPy-based board
    \item Win condition checking
    \item Data recording in history.csv
    \item GUI for all interactions
    \item Leaderboard display and sorting
    \item Statistical graph generation using Matplotlib
    \item Game over menu with options to play again, return to main menu, or show leaderboard
\end{itemize}
